# Responsible AI Policy

The copilot assists support staff; it does not make the final support decision. Drafts are generated from approved playbooks, include a confidence score and citation, and remain in `pending` status until a human explicitly approves, edits, or rejects them.

Never ask builders for private keys, seed phrases, API secrets, or other credentials. Read-only public RPC lookups are allowed for diagnostics. Security reports must be escalated using the approved security workflow.
